**Bubble Sort Algorithm**

Here we will say how bubble sort worksout, Bubble Sort works by sorting the highest value at the end of the array and sorting out similarly. Like there is an array of 10 elements in length so it will take the highest value element to the last of the array or (9th Position of an array), similarly followed by second highest at the 8th position and so on.

Here the bubble name comes from how this algorithm work, it makes the highest value bubbled up.

In more depth it works like when an inner loop that goes through the array and swaps values if the first value is higher than the next value. This loop must loop through one less value each times and there is an outer loop that controls how many times the inner loop must run. For an array with n values, this outer loop must run n-1 times.
