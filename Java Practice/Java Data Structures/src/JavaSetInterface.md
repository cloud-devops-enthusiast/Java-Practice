The Set is part of the Java Collection Framework and is used to store a collection of unique elements.
Unlike a List, a Set does not allow duplicates, and it does not preserve the order of elements (Unless you're using TreeSet or LinkedHashList).
Common classes that implement Set:
- HashSet: fast and unOrdered
- TreeSet: sorted set
- LinkedHashSet: Ordered by insertion

Common Set Methods:
- add(): Adds an element if it's not already in the set
- remove(): Removes the element from the set
- contains(): Checks if the set contains the element
- size(): Returns the number of elements
- clear(): Removes all elements
