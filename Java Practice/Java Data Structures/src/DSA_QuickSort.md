**Quick Sort**

Quick Sort is one of the fastest sorting algorithms. 

Quicksort algorithm takes an array as input and considers one of the element as pivot element. It chooses one element as the pivot element and moves the other values to the left of the pivot element and higher values to the right of the element.

Consider a pack of cards with different numbers written on them, so you take one card out of them which acts as a divider, so now you move all the cards with small numbers to the left and the larger numbers to the right, now sort the left and right sections of cards doing the sorting same way. At last repeat it with every section so at end you will only have one card left.
