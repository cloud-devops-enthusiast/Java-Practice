**Java Exception Handelling**

Whenever an exception happens, Java will normally Stop and Generate an error message.

This is mostly done with the code which is suspected to throw an error or exception.

There are some keywords which are used in exception handelling like:

*Try:* The try statement allows you to define a block of code to be tested for errors while it is being excecuted.

*Catch:* The catch statement allows you to define a block of code to be executed, if an error occurs in the try statement.

**Below mentioned is the syntax of Exception Handling in java.**
            try{

            }
            catch{

            }
